# Trillion AI Tech

Trillion AI Tech is an independent AI and interactive technology studio based in Aotearoa New Zealand.

This website is the public home of the studio and presents our current direction across:

- Apps
- Games
- Agent systems
- Tools

## About

Trillion AI Tech focuses on building small, sharp software, playable systems, model-driven assistants, and internal workshop tools.

The studio is currently in build phase. Products are in development, prototypes are being explored, and early collaborators, testers, and technical partners are welcome.

## Website purpose

This website exists to:

- Introduce the Trillion AI Tech studio
- Show current work in progress
- Present ideas and prototype projects
- Share the studio’s design and development approach
- Provide a way for collaborators and interested users to get in touch
- Support future paid products and subscriptions
